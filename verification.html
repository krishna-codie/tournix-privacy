ℹ️ Privileged Intents Required

Tournix requires the following Discord Privileged Intents to function correctly:

  • Server Members Intent: Required to access member counts, user information, and server member lists across all guilds.
  • Message Content Intent: Required to process user commands and provide interactive bot functionality.

These intents are essential for delivering the full Tournament Management, Leaderboards, and User Information features that server owners expect from Tournix.
