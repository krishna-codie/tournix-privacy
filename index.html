Privacy Policy

This policy outlines how Tournix collects, uses, and protects your data to ensure transparency and compliance with Discord Developer Guidelines.

🔍

Minimal Collection

We only store essential IDs & settings needed for tournament operations.

🔒

Strictly Confidential

Data is stored in encrypted databases and is never sold or shared.

⏳

30-Day Retention

Command execution logs are automatically deleted after 30 days.

🗑️

Deletion Rights

Server owners can request full removal of server configuration data.

1. Data Collection

Tournix collects only the minimum information required to provide its features and operate correctly. This may include:

  • Discord Server IDs: Used to attach custom configuration settings and server permissions.
  • Discord User IDs: Used to associate tournament registrations, leaderboards, and user scores.
  • Channel IDs: Used to direct bot notifications, tournament logs, and active status updates.
  • Configuration Settings: Custom options created and saved by server administrators.
  • Tournament, Leaderboard & Moderation Data: Saved match scores, ranking brackets, and moderation parameters.
🛡️

Security Commitment: Tournix does not collect passwords, payment information, or message content except when processing commands that users intentionally send directly to the bot.

2. Data Usage & Storage

Collected data is used solely to provide and maintain the bot's features, including:

  • Tournament management
  • Leaderboards
  • Server configuration
  • Moderation & utility features
  • Security and abuse prevention

Data is stored securely in encrypted databases and is never sold, rented, or shared with third parties except where required by law.

3. Logging

Command execution logs may be retained for up to 30 days to assist with debugging, abuse prevention, and technical support. Logs are automatically deleted after the retention period unless a longer retention period is required to investigate security issues.

4. Server Invite Links

When Tournix joins a server, it may generate an invite link that is securely stored by the developers. This invite is used only for customer support, troubleshooting, or premium reward verification when requested by the server owner. The invite is never shared publicly or used for advertising.

5. Your Rights

Server owners may request deletion of their server's stored configuration data by contacting the Tournix support team. Upon receiving a valid request, eligible data will be removed unless it must be retained for legal or security reasons.
